PiggyPet for Windows
====================

一只住在桌面上的小猪：在屏幕左下角睡觉，点它会换表情，可以拖着走，
偶尔自己溜达一圈，兴致来了还会拱一下鼠标。

系统要求
--------
Windows 10 (1903 或更新) / Windows 11，64 位。
不需要安装 .NET 运行时：Windows 自带 .NET Framework 4.8。

怎么用
------
- 双击 PiggyPet.exe 启动。没有任务栏图标，猪就睡在屏幕左下角。
- 左键点它：换一个表情（共 35 种，含 5 条文字表情）。
- 按住拖动：搬家，松手后位置会被记住。
- 右键：打开菜单。
  换个表情 / 到处逛逛 / 追着鼠标
  调皮模式（默认关）
  拱鼠标频率：从不 / 偶尔 / 经常
  气泡文字
  兴奋程度：低 / 中 / 高（决定它多久自己溜达一次）
  走路速度：慢悠悠 / 正常 / 利索
  开机自启（可随时关掉）
  回到左下角 / 关于 PiggyPet / 退出 PiggyPet

首次启动会问一次要不要开机自启，之后可以在菜单里随时改。
设置保存在 %APPDATA%\PiggyPet\settings.json。

第一次运行被拦住了？
--------------------
exe 没有购买代码签名证书，Windows SmartScreen 可能提示"Windows 已保护你的电脑"。
点"更多信息" → "仍要运行"即可。杀毒软件误报也是同一个原因。

猪不见了？
----------
1. 看一眼屏幕左下角，或者别的最小分辨率边缘。
2. 右键菜单 → 回到左下角（如果还能点到它）。
3. 它可能被拖到了多显示器的工作区之外，重启一次会自动拉回。

出问题了？
----------
%TEMP%\piggy-error.log 里有崩溃日志，%TEMP%\piggy-debug.log 是 --debug 模式下的运行日志。
带着日志去 https://github.com/Franky100-pig/PiggyPet/issues 提 issue，谢谢。
